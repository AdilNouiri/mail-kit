# T5 decisions — preview gallery and mockup comparison

Date: 27 November 2026.

## D1 — Stub list settled (T2 merged, e825f1d)

T2 (de1e1b3) is merged; the `t2Ready` guards and "waiting for T2" placeholders are gone:
the real F2.7 comparison and the real-renderer command test run unconditionally, and a
missing browser fails them with the install command.

A first F2.7 run on `majordome-magic-link` failed (0.94%, 2.23%, 2.92%, 7.99%): the sample

twice. Fixed by `task/t4b-sample-link` ed870bd (merged); all views pass. The threshold
stays 1% (`THRESHOLD = 0.01`; pixelmatch colour threshold 0.1 is the library default).

## D2 — Comparison method

`pixelmatch` (colour threshold 0.1) between the preview PNG and the PNG of `spec/images/`,
same sizes, viewport-only screenshots, `--hide-scrollbars`, context `colorScheme`. Phone
views use a real 390 px viewport instead of the mockups' iframe-and-crop; the media
queries see the same width. Mail-kit vs the committed PNGs is the F2.7 reading ("rendered
by build-mockups.mjs"); the harness test covers the screenshot method itself.

## D3 — Choices

- `preview/` is flat (`<theme>-<sample>.html`, `.txt`, `png/<pair>-<scheme>-<view>.png`,
  `index.html`) and holds a copy of `assets/<theme>/`; logo and web-font URLs are replaced
  by their local path found by file name (`assets/<id>/<file>` or `assets/<id>/fonts/<file>`).
- Every non-`file:` request is aborted and recorded; F5.3 asserts there is none.
- `CCS_TEST_CHROME` set but missing counts as no browser (never a silent fallback).
- No change to `vitest.config.ts`; `test:mockup` runs the comparison file only.

## D4 — F2.7 compares like with like (to reread: yes)

CI on Ubuntu failed F2.7 at 1.024 % (majordome-magic-link, light desktop), and the harness
check (mockup html vs committed PNG) failed the same way: Linux text rasterization differs
from the Mac-made PNGs of `spec/images/`, not the renderer. F2.7 now renders the mockup html
(`spec/images/src`) with the same browser, sizes and colour scheme in the same run and
compares the mail-kit render with that, on every platform. The comparison with the committed
PNGs stays as the harness test, run only when `process.platform === "darwin"` (named
"harness (macOS only)", so the skip is visible). The 1 % limit and the pixelmatch colour
threshold 0.1 are unchanged. Departs from D2 on what the reference is.
