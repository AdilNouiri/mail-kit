## D2: F8.5 deviation, `prefers-color-scheme` kept for Outlook.com

F8.5 says the `prefers-color-scheme` rules are removed. caniemail documents Outlook.com as
supporting them (`css-at-media-prefers-color-scheme`, outlook-com `y #3`; note 3 adds data
attributes in dark mode). A rule without a source is not applied, so they are kept. The
screenshot is light, so the choice changes nothing in the light layout. Dark Outlook.com is
not checked.

## D3: Gmail variant B source is partial

The only source for "no `<style>` with a non-Google account" is C `html-style` note 2, listed
for Gmail iOS and Android. The desktop-webmail entry has no such note, so variant B is the
documented worst case for the app with a non-Gmail account, applied at 1280 as F8.3 asks.

## D4: F8.4, Quick Look does not render the `.eml` in the guest; WebKit fallback

In the sandbox guest (macOS 27.0), `com.apple.mail.MailQuickLookExtension(16.0)` is
registered (`pluginkit`), `mdls` types the file `com.apple.mail.email`, and
`qlmanage -p /etc/hosts` opens a window. `qlmanage -p` on the `.eml` (also with
`-c com.apple.mail.email`) opens no window and prints nothing; the guest has no Mail
account. Runs of 28 November 2026: `20261128-063610-t12-client-checks-17f3` (the committed
`apple-mail/run.sh`; guest in light then dark, no Quick Look window in either) and
`20261128-063926-t12-client-checks-7825` (`/etc/hosts` window as control, `.eml` windows
absent). The spec's fallback applies: `test/clients/webkit.ts` shows the unmodified mails in
Playwright's WebKit (Apple Mail renders html with WebKit), headless, light and dark, at 1280
and 390. F8.4 is **emulated**, not a real renderer. `apple-mail/run.sh` stays as the recipe to
retry on a guest where the extension renders; it is not part of `npm run check`.

## D5: Layout of the recipes

- `node test/clients/run.ts [out]` renders every theme x sample pair (6), writes the Gmail A,
  Gmail B and Outlook.com pages and 24 screenshots with `$CCS_TEST_CHROME` (default `preview/clients`),
  measures banner, footer, button background and the widest element of the card (all 600 px
  at 1280), and rewrites the `.eml` files.
- `node test/clients/webkit.ts [out]` takes the 24 WebKit screenshots.
- The `.eml` files are committed under `test/clients/apple-mail/eml/` because the sandbox
  copies only non-ignored files and the guest has no Node. `clients.test.ts` fails when one
  differs from `renderMail`.
- `playwright-core` was already a dev dependency; Playwright's WebKit (`npx playwright-core
  install webkit`) is a test tool in the cache, not in `package.json`.
