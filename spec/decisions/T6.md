# T6 decisions — release, consumer fixtures, README

Date: 27 November 2026.

## D1 — Release build uses `--lib es2022,webworker` (departs from T0 D5)

`decisions/T0.md` D5 says the release build compiles `src/` with `--lib es2022 --types ""`.
With tsc 7.0.2 that fails: `src/escape.ts` and `src/theme.ts` use `URL`, which only the
DOM, WebWorker or Node libs declare. `webworker` matches the Worker target and has no
`document` or `window`; `URL` exists in Workers and Node. The emitted `.d.ts` files
reference no such type. `scripts/release.ts` passes `--lib es2022,webworker --types ""`.
Biome still bans DOM globals in `src/`.

## D2 — Release flow (replaces "removes dist/ from the default branch again", `11-tasks.md` T6)

`main` is reached only through pull requests, so the script never pushes it. In a temporary
clone of `main`'s HEAD (real mode refuses unless local HEAD equals `origin/main`, the tree
is clean and the tag exists neither locally nor on origin), it builds `dist/`, makes ONE
commit adding `dist/` (`git add --force`) on a detached HEAD, a child of `main` on no
branch, tags `v<version>` on it and pushes only `refs/tags/v<version>`. `main` never holds
`dist/`, so there is no removal commit. `--dry-run` does the same and pushes nothing;
`--pack <dir>` also writes the `npm pack` tarball. The script refuses a `src/types.ts`
`VERSION` that differs from `package.json` (F6.5).

## D3 — Fixtures

`npm run test:worker` and `test:node` both run `test/consumers/prepare.ts`, which makes a
dry-run build of the working tree (tracked and untracked files not ignored, so the check
tests uncommitted work), packs it and installs the tarball (`--no-save`,
`--ignore-scripts`) into `test/consumers/<fixture>/node_modules` (ignored). The Worker
fixture runs under `@cloudflare/vitest-plugin`; the Node fixture is plain `.mjs` for
`node --test`; both also render the three samples with `dream-studio`. F6.1, F6.4 (static
and dynamic imports, `require`) and F6.5 are tested in
`test/consumers/release/release.test.ts` (run by `test:node`, since `vitest` excludes
`test/consumers/**`); it installs the tag from a `git+file://` URL without
`--ignore-scripts`. The release test itself builds from committed HEAD. The Node 22 run is
not exercised here: the Mac has Node 24 (found work: a Node 22 job in
`.github/workflows/check.yml`, T8's file).
