# T3 decisions: plain-text part

Date: 27 November 2026.

## Stub to switch at merge time

`src/text.ts` holds a local `LABELS` constant (`Code` and the colon, `" :"` for fr, `":"` for
en) because T1's `src/i18n.ts` is built in parallel. At merge, replace it with the
`i18n.ts` strings and delete the constant. The button separator and the footer-link
separator use the same colon.

## Choices

- Preheader and wordmark are not in the text part: F3.1 covers blocks and footer.
- Inline link renders `text (url)`; bold renders plain.
- `link` block renders `lead url`, wrapped on spaces, URL never broken.
- Footer: `--`, reason (`footerReason` or theme's), legal, then `label: url` when a link exists.
- Heading whitespace is collapsed and underlined with `=` of the same length (not wrapped).
- Spaces are plain (no NBSP), so the output matches the spec's literal lines.
- Tests build `Theme` through a local helper casting the brand.
